# Connector index

Lettered pentagons are package-wide off-page continuation codes. Each code below identifies its actual destination flow, diagram page and node. Numbered circles are local to the specified page; a repeated number on another page is a separate connector.

This model contains 329 lettered codes and 210 page-local numbered connector groups.

Source and destination links open the exact page PNG. Use the flow/page ID and atlas-page column to locate the same editable page inside the complete role atlas. Multiple source endpoints may share one destination.
