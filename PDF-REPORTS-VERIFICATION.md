# SiteTrace PDF exports — Task 4

Implemented 15 October 2026. No push or deployment. All database/browser tests use an isolated local PostgreSQL fixture; external HTTPS is blocked in the browser harness.

## Export inventory and permissions

| Existing surface | Existing authorized roles | Exported data |
| --- | --- | --- |
| Activity Logs, both portal entry points | Admin, Engineer, Architect, Tool Handler | All activity in the existing authorized movement snapshot, sorted newest first and filtered by the current search |
| Reports: Current inventory | Admin | All positive-quantity records from the existing monitoring response; current state, irrespective of the historical date range |
| Reports: Saved inventory snapshot | Admin | The selected immutable snapshot in the loaded reporting period |
| Reports: Movement history | Admin | All events from the loaded inclusive Manila date range |
| Secretary | Neither export route | No added access |

The original exports use complete arrays, without frontend pagination. The PDF paths use those same arrays and existing RPCs. No permissions, authentication code, SQL, migrations, custody records, or hosting settings were changed. Searches found no other working CSV report exporters or CSV import controls in the application. QR/equipment-label printing remains unchanged.

The unreachable legacy `2-engr/modules/reports/reports.html` had inert Excel/PDF buttons. Those controls were removed; the route remains restricted. Historical user manuals and their old screenshots are pre-change documentation, not additional application export implementations.

## Report behavior

Reports include SiteTrace / MCPA branding, MCPA Build Right Corp., title, generation time in Philippine time, filters/snapshot scope, record count, A4 tables, repeated headers, alternating row fills, wrapped text, and “Generated by SiteTrace” with page/total counts. Current six/seven-column reports use landscape; the renderer supports portrait for narrower tables.

Activity exports retain every original timestamp string, including fractional seconds and offset, alongside full Manila date/time. Readable action names retain the original action code. References, recorded-by names, tool IDs and details remain intact. Formula-like names are literal text, with no CSV-specific alteration.

Changing the reporting period disables export until that period has loaded. Failed loads cannot export stale data. Empty results produce a clearly marked zero-record PDF. Repeated clicks share one download lock, including when activity refresh replaces the button. Exports recheck the account/role after loading assets and do not fetch additional records.

All assets are committed and loaded from the same site; PDF generation has no CDN, backend or paid-service dependency. Noto Sans embeds Filipino names, accented text, peso signs and common symbols. Characters outside its coverage (for example CJK/emoji) use explicit `[U+XXXX]` notation, with an explanatory PDF note, so their code points are preserved rather than dropped.
